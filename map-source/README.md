# Камеры фиксации ПДД Самарской области

Откройте **samara-cameras.html** двойным щелчком. Для подложки OpenTopoMap нужен интернет. Точки, поиск, фильтры и карточки хранятся в HTML и доступны без интернета.

Введите город, улицу, номер трассы, модель или ID. Выберите вид нарушения и нажмите **Показать найденное**, чтобы приблизить результаты. Нажмите на метку или строку списка, чтобы открыть карточку. Число в крупной метке показывает количество сгруппированных мест. На отдельной метке число показывает количество записей реестра с одинаковыми координатами.

## Источники

- [Реестр Госавтоинспекции, Самарская область](https://госавтоинспекция.рф/r/63/milestones/?page=1), отметка обновления **08.11.2026**. Встроенная карта реестра содержит **1 397 уникальных записей на 733 местах**. На 70 страницах списка нашлось **1 050 уникальных записей с адресом**. Некоторые ID повторяются на разных страницах.
- [Региональный перечень стационарных и передвижных средств фиксации](https://госавтоинспекция.рф/upload/site63/report/publication/file/11.09.2026.xls) от **11.09.2026**, **766 строк**. По точному совпадению обеих координат удалось связать перечень с 702 местами из карты реестра. Для 701 из них указаны конкретные нарушения. Для совпадающих мест карточки показывают формулировки из перечня и номера строк. Виды нарушений и направления относятся к месту установки. Перечень не связывает их с отдельными ID устройств на этом месте.
- Адрес места берётся из списка реестра или из строки перечня с теми же координатами. Для **двух мест** доступные записи не содержали адрес. Для **32 мест реестра** конкретный вид контроля не указан. **59 мест**, опубликованных только в сентябрьском перечне, доступны через отдельный переключатель.

## Обновление на Windows

Держите **samara-cameras.html** и **update.py** в одной папке. Для обновления нужен Python 3. Откройте PowerShell в этой папке.

1. Чтобы обновить точки, адреса и дату реестра, выполните:

   ```powershell
   py -3 .\update.py
   ```

2. Чтобы обновить сведения о нарушениях и направлениях, скачайте последнюю таблицу для Самарской области в разделе «Сведения по Самарской области» на [сайте Госавтоинспекции](https://госавтоинспекция.рф/r/63/). Для файла XLS скрипт использует LibreOffice. Если у вас Excel, можно открыть XLS и сохранить его как XLSX. Подставьте путь к скачанной таблице и дату публикации, указанную рядом с ней:

   ```powershell
   py -3 .\update.py --report-only --report "C:\путь\к\перечню.xlsx" --report-date ДД.ММ.ГГГГ
   ```

   Чтобы обновить оба источника за один запуск, уберите `--report-only`. Если известна прямая ссылка на новый перечень, передайте её через `--report-url "https://…"`.

3. После сообщения с количеством записей снова откройте HTML или обновите вкладку.

Если реестр недоступен или изменился формат выгрузки, программа остановится и сохранит предыдущий HTML. Обновление перечня отдельно продолжает работать с локальным файлом. Дата реестра и дата перечня обновляются независимо.
